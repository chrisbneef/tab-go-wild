# Blog / content roadmap — 20 topics by intent

Priority = intent × how winnable it is for a new site. Publish ~2/week. Each post: answer the question in the
first 2–3 sentences (answer engines quote that), cite sources for any number, link to the matching service
page, city page and cost guide, and add FAQPage schema for the Q&A block. New pages go in `src/pages/` (or
add a `src/content/blog` collection when you start).
